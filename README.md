# Automation Portfolio Projects

Public-safe automation showcase projects for Fiverr and GitHub. Each demo uses synthetic data, Python standard library only, modular code, tests, documentation, and human-in-the-loop outputs.

## Featured Showcase Projects

- `lead-intake-ai-router`: lead scoring, validation, routing, and follow-up review queue.
- `webhook-debugger-starter-kit`: local JSON payload validation, event routing, and debug logs.
- `automation-health-monitor`: workflow failure detection, latency checks, and retry planning.
